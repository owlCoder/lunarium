# Security Policy

## Supported versions
Lunarium is a pre-release project. Security fixes target the latest development branch until a stable release exists.

## Reporting a vulnerability
**Please do not post exploitable vulnerabilities in public issues.** Use GitHub's **Report a vulnerability** / private vulnerability reporting option when enabled for this repository, or contact the maintainer privately through their GitHub profile.

Include a concise description, reproduction steps, affected macOS version, and a safe proof of concept if available. Do not provide real user screenshots or sensitive information.

## Security model
Screen Recording permission is managed by macOS. Lunarium only requests it for user-triggered capture. Screenshot pixels remain local; there is no telemetry, network upload, or remote image hosting service in the application.
